======================================================================
GUIA DE CONSULTA: ESTRUTURA DE REPETIÇÃO - FOR - PYTHON
======================================================================
Usado quando você SABE com antecedência quantas vezes quer repetir, 
ou para percorrer coleções (listas, strings, dicionários, etc).

1. O COMANDO range() - O MAIS COBRADO EM PROVAS
----------------------------------------------------------------------
O range() gera uma sequência de números. Ele aceita até 3 argumentos:
Sintaxe: range(inicio, fim_exclusivo, passo)

# Apenas 1 argumento: range(fim) -> Começa do 0 e vai até (fim - 1)
for i in range(4):
    print(i) # Imprime: 0, 1, 2, 3

# 2 argumentos: range(inicio, fim) -> Vai do inicio até (fim - 1)
for i in range(2, 6):
    print(i) # Imprime: 2, 3, 4, 5

# 3 argumentos: range(inicio, fim, passo) -> Pula de 'passo' em 'passo'
for i in range(1, 10, 2):
    print(i) # Imprime: 1, 3, 5, 7, 9

# Range invertido (contagem regressiva): passo precisa ser negativo
for i in range(5, 0, -1):
    print(i) # Imprime: 5, 4, 3, 2, 1

2. PERCORRENDO COLEÇÕES (Iteração)
----------------------------------------------------------------------
# Em Listas, Tuplas ou Conjuntos:
frutas = ['maçã', 'banana']
for fruta in frutas:
    print(fruta)

# Pegando o ÍNDICE e o VALOR ao mesmo tempo (Usa enumerate()):
for indice, fruta in enumerate(frutas):
    print(f"Índice {indice}: {fruta}") # Saída: Índice 0: maçã...

# Em Strings:
for letra in "Oi":
    print(letra) # Imprime 'O', depois 'i'

3. COMANDOS DE INTERRUPÇÃO (break e continue)
----------------------------------------------------------------------
# break: Interrompe e ENCERRA o loop imediatamente.
for n in range(1, 10):
    if n == 5:
        break
    print(n) # Só imprime: 1, 2, 3, 4

# continue: Pula o resto do código DESTA rodada e vai para a PRÓXIMA.
for n in range(1, 5):
    if n == 3:
        continue
    print(n) # Imprime: 1, 2, 4 (pulo o 3)

4. O ELSE NO FOR 
----------------------------------------------------------------------
O bloco 'else' associado ao 'for' SÓ é executado se o loop terminar 
naturalmente (chegar ao fim da sequência). Se o loop for interrompido 
por um 'break', o 'else' NÃO roda.

for x in range(3):
    print(x)
else:
    print("Loop terminou normal!") # Esse print VAI rodar.
